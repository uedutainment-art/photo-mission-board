한 팀 → 전체 팀 · 줌아웃 연출 (4프레임)

행사 마지막 빔프로젝터에서 운영자가 키를 누르면 시작. 한 팀의 모습이 점점 작아지면서 모든 팀의 콜라주가 같은 화면에 나타나는 연출.

한 팀 클로즈업
FRAME 2

FRAME 3
전체 팀 등장
FRAME 4
전체 콜라주 완성

⟶ 시간 흐름은 약 2~3초. CSS transform: scale()과 grid-template-columns 보간으로 부드럽게 처리.

이 흐름에서 정해진 동작

  • 운영자 설정 · 첫 입장 모드 — "셀카 / 단체사진 / 없음" 3개 중 선택. 기본은 셀카
  • 셀카 모드 — 모든 팀원이 각자 셀카 1장씩 올려야 미션 시작 가능. 한 팀이 들어가면 "다음 단계로 가려면 모두 셀카를 올려주세요" 안내
  • 그리드 자동 결정 — 등록된 팀원 수에 따라 자동 (2×2 / 3×2 / 5×2 등). 정확히 N명을 미리 알 필요 없이 첫 입장한 사람부터 차곡차곡 채워짐
  • 모자라는 자리 — 등록된 팀원이 6명인데 5명만 셀카 올렸으면 마지막 칸은 어두운 팀 컬러로. 빈 자리도 디자인의 일부
  • 큰 배너는 팀 홈 상단에 고정 — 누군가 새로 셀카 올리면 즉시 반영. 행사 내내 팀의 정체성 표시
  • 줌아웃 연출 — 행사 마지막에 빔프로젝터에서 운영자가 키 누르면 시작. 한 팀 → 6개 팀 → 10개 팀 → 전체 콜라주 순으로 약 2-3초간 부드럽게 줌아웃
  • 한 팀 콜라주의 위상 — 별개의 결과물이 아니라 "팀의 사진 중 하나"로 취급. Export 시 ZIP에 포함
SCENE 6 · CROP METHODS COMPARISON

사진 크롭 처리 · 4가지 방법 비교

같은 셀카 한 장이 각 방법에서 어떻게 1:1 셀에 들어가는지. 노란 원이 얼굴.
원본 사진
3:4 세로 셀카. 얼굴은 위쪽 1/3 지점에 있음.
METHOD 1
자동 중앙 크롭object-fit: cover
✕ 얼굴 잘림

CSS 한 줄. 사진 중앙만 잘라내서 셀카는 머리/턱이 잘리기 쉬움. 코드 작성 0초.

METHOD 2
수동 위치 조정object-position: 50% 20%
△ 사람 손 필요

사진별로 "어디를 중심으로 보일지" 좌표 저장. 운영자/참가자가 슬라이더로 조정.

METHOD 3
자동 얼굴 인식face-api.js (브라우저)
★ 셀카 최적

얼굴 좌표를 자동 인식해 중심에 배치. 참가자/운영자 손 안 댐. 셀카는 99% 잘 됨.

METHOD 4
참가자 직접 크롭업로드 시 드래그
◎ 통제력 최고

업로드 화면에서 1:1 박스를 직접 끌어서 위치 잡기. UX 단계가 늘어남.

우리 앱의 권장 조합 (단계별)

  • v1 (즉시 가능) — object-fit: cover 기본 + 검수 화면에 위치 조정 슬라이더. 모든 사진은 일단 자동 표시되고, 운영자가 보다가 어색한 것만 슬라이더로 보정. METHOD 1 + 2 조합
  • v1.5 (셀카 한정 자동화) — 셀카 배너에 face-api.js 적용. 라이브러리 ~1MB, 브라우저에서 돌고 서버 비용 0. 셀카는 사용자가 아무것도 안 해도 얼굴 중심으로 잘림. METHOD 3
  • v2 (정성 들이는 행사) — 업로드 시 참가자가 직접 크롭. 모바일 드래그 UI 필요. METHOD 4
  • 크롭 정보는 메타데이터로 저장 — 원본 사진은 절대 자르지 않음. { x, y, scale } 같은 좌표만 슬롯 문서에 저장. 화면 표시·콜라주 합성 때 그 좌표대로 잘라냄. 나중에 액자·영상용으로 원본 받는 요구사항과 자연스럽게 맞물림
  • 모든 사진은 두 가지 버전으로 저장 — 원본 1장 + 1:1 1024px 썸네일 1장. 보드/콜라주에는 썸네일 사용 (빠름), Export에는 원본 + 좌표 기반 합성

  • 두 화면 분리 — 빔프로젝터는 "공개 보드" 페이지만 띄움 (운영자 UI 없음). 운영자 본인은 폰에서 컨트롤 카드로 조작. 두 화면이 같은 Firestore 구독으로 동기화
  • 3가지 뷰 모드 — (1) 전체 보드 (기본) / (2) 한 팀 클로즈업 (팀 정보·셀카·미션 사진) / (3) 줌아웃 연출 (SCENE 5의 4프레임 애니메이션)
  • 자동 슬라이드 — 행사 중 BGM처럼 깔아두기 좋음. 각 팀 8초 + 전체 보드 15초 식으로 순환
  • 줌아웃 피날레 — 행사 종료 시점에 1회용. 운영자가 박수·BGM 타이밍에 맞춰 트리거. 한 팀 → 6팀 → 10팀 → 전체 콜라주로 3초간
  • 실시간 반영 — 새 사진 업로드되면 빔프로젝터에도 즉시 (Firestore onSnapshot). 새로 채워지는 칸은 살짝 페이드인 애니메이션
  • 인터넷 끊겨도 일정 시간은 캐시로 표시 — Firestore offline persistence로 마지막 상태 유지. 5초 이상 끊기면 우측 상단에 ⚠ 표시
